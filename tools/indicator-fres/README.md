# Indicator Frequency Response (`indicator-fres`)

A standalone, zero-dependency browser utility for visualizing digital filter / trading indicator frequency responses and exporting publication-quality SVG and 2x PNG illustrations. Inspired by `projects/mb/src/lib/charts/frequency-response-chart/` and modeled directly on `tools/indicator-study/` — single HTML file, D3 v7 from CDN, no build step.

## Quick Start

1. Open `index.html` in any modern browser
2. Click **Load JSON** (or drag and drop files onto the window) and select `examples/example-fres-data.json`
3. Optionally load a layout file (e.g. `examples/example-fres-layout-grid-2x2.json`) to customize styling or multi-pane subfigures
4. Export via **Save SVG** or **Save PNG**

### URL Parameters

```text
?data=path/to/fres-data.json
?data=path/to/fres-data.json&layout=path/to/fres-layout.json
?data=path/to/fres-data.json&layout=path/to/fres-layout.json&theme=print
```

Local JSON URLs require an HTTP server or embedded HTML snapshot because browsers restrict `file://` fetches. See [RUNNING.md](RUNNING.md) for one-line launch commands and `make-fres.cjs` usage.

## Concepts

### Data File (`fres-data.json`)

Contains precomputed frequency-response spectra (generated by `ifres` or `FrequencyResponse.calculate`). Self-sufficient — loading a data file alone renders immediately with automatic layout.

```json
{
  "description": "Moving averages frequency response (N=1024)",
  "signalLength": 1024,
  "frequencies": [0.001956947, "... up to 1.0"],
  "series": {
    "sma-14": {
      "mnemonic": "sma(14)",
      "warmup": 14,
      "powerDecibel": { "min": -70, "max": 0, "data": [...] },
      "powerPercent": { "min": 0, "max": 100, "data": [...] },
      "amplitudeDecibel": { "min": -70, "max": 0, "data": [...] },
      "amplitudePercent": { "min": 0, "max": 100, "data": [...] },
      "phaseDegrees": { "min": -180, "max": 180, "data": [...] },
      "phaseDegreesUnwrapped": { "min": -900, "max": 0, "data": [...] }
    }
  }
}
```

### Layout File (`fres-layout.json`)

Optional presentation file controlling modes, axis domains, palettes, reference lines, annotations, and multi-chart subfigure grids (`(a)`, `(b)`, `(c)`, `(d)` exported together as a single SVG).

```json
{
  "columns": 2,
  "legend": "shared",
  "palette": "tab10",
  "charts": [
    { "subfig": "(a)", "xMode": "period", "maxPeriod": 50, "yMode": "amplitudePct", "horizontals": [50, 70.71] },
    { "subfig": "(b)", "xMode": "period", "maxPeriod": 50, "yMode": "phaseDegUnwrapped", "minDeg": -360, "maxDeg": 45 }
  ]
}
```

## Features

- **6 response components**: Power (dB), Power (%), Amplitude (dB), Amplitude (%), Wrapped Phase (°), Unwrapped Phase (°)
- **2 X-axis domains & 2 scales**: Normalized frequency `(0, 1]` or cycle period `[2, ...]` samples, with **Linear** or **Log** scaling
- **Single-chart or multi-pane subfigures**: Arrange `(a)`, `(b)`, `(c)`, `(d)` stacks or multi-column grids into one composite SVG
- **Reference lines & 6 annotation types**: Domain-expanding `horizontals` / `verticals` (e.g. `-3 dB`, `50%`, cutoff period) plus static or `draggable` `hline`, `vline`, `text`, `arrow`, `zone`, and `line` annotations
- **Interactive legend & inspection**: Click legend items to highlight curves; inspect values with hover coordinates (`x ⇆ y`) or full crosshair with axis callouts
- **3 built-in themes + Theme Editor**: `Light`, `Dark`, and publication-ready `Print (B&W)` (with automatic curve dash differentiation), plus live CSS token editing
- **Live Layout & Data Editors**: Edit, format, copy, and save both `fres-layout.json` and `fres-data.json` inline (`Ctrl+Enter` to apply)
- **Export**: Standalone SVG (with resolved theme CSS embedded) and 2x retina PNG
